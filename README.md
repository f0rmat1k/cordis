# cordis

Звонки друзьям прямо в браузере: список контактов, звонок в один клик, нейросетевое шумоподавление.

- **Звук** идёт напрямую между собеседниками (WebRTC, кодек Opus 64 кбит/с). Сервер только знакомит их.
- **Шумодав** работает в браузере того, кто говорит. Режимы (переключаются прямо во время звонка):
  - **GTCRN** — нейросеть, по умолчанию. Режет клавиатуру, вентиляторы, гул, фоновые голоса.
  - **RNNoise** — нейросеть полегче и постарше. Похоже на «стандартный» шумодав Discord до Krisp.
  - **Встроенное в браузер** — обычный WebRTC-шумодав.
  - **Выключено**.
- **Контакты** взаимные: добавил друга — ты появился у него. Можно отправить ссылку-приглашение
  (`https://адрес/?add=твоё_имя`): друг откроет её, введёт имя, и вы сразу в контактах.
- Аккаунт — просто имя. Браузер запоминает его, пароль не нужен.

## Запуск на своём ПК (белый IP)

Браузеры дают доступ к микрофону только по **HTTPS**. Порты 80/443 не нужны: сайт работает на отдельном порту
(по умолчанию 8443), а сертификат Let's Encrypt Caddy получает через DNS-проверку бесплатного [DuckDNS](https://www.duckdns.org).

1. На duckdns.org войти, создать поддомен (например `mycordis`), указать в нём свой внешний IP и скопировать token.
2. Установить Caddy и добавить в него модуль DuckDNS:
   ```bash
   winget install CaddyServer.Caddy
   ```
   ```bash
   caddy add-package github.com/caddy-dns/duckdns
   ```
   Если `add-package` не сработает, готовую сборку можно скачать на https://caddyserver.com/download, отметив пакет `caddy-dns/duckdns`.
3. Поставить зависимости (один раз):
   ```bash
   npm install
   ```
4. На роутере пробросить на этот ПК **TCP 8443** (или другой выбранный порт) и открыть его в брандмауэре
   (PowerShell от администратора):
   ```powershell
   New-NetFirewallRule -DisplayName "cordis" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow
   ```
5. Первый запуск (параметры запомнятся в `local-config.json`):
   ```bash
   powershell -ExecutionPolicy Bypass -File start.ps1 -Domain mycordis.duckdns.org -Token ВАШ_ТОКЕН -Port 8443
   ```
   Дальше достаточно `start.ps1` без параметров. При первом запуске получение сертификата занимает до минуты.
6. Отправить друзьям `https://mycordis.duckdns.org:8443` или ссылку-приглашение из приложения.

Если на машине с основным сайтом стоит nginx/Caddy и у сайта есть свой домен, можно вместо этого завести
поддомен (например `call.вашсайт.ru`) и проксировать его на `http://<IP этого ПК>:3000` с поддержкой WebSocket.
Тогда Caddy здесь не нужен.

Для локальной проверки без HTTPS хватит `npm start` и http://localhost:3000. На `localhost` микрофон работает и без сертификата.

## Если звонок соединяется, но звука нет

Значит, у кого-то из собеседников строгий NAT (бывает у мобильного интернета и некоторых провайдеров)
и прямое соединение не пробивается. Нужен TURN-сервер, который будет пересылать звук.
Например, бесплатный тариф [Metered](https://www.metered.ca/stun-turn) или свой coturn. Параметры передаются через переменные окружения:

```bash
TURN_URL=turn:example.com:3478 TURN_USER=user TURN_PASS=pass npm start
```

## Устройство

| Файл | Что делает |
|---|---|
| `server.js` | Раздаёт страницу, хранит пользователей и контакты (`data/users.json`), пересылает сигналы WebRTC через WebSocket |
| `public/audio.js` | Цепочка микрофона: getUserMedia → шумодав (AudioWorklet + WASM) → WebRTC |
| `public/app.js` | Интерфейс, контакты, логика звонка |
| `Caddyfile`, `start.ps1` | HTTPS и запуск |

Шумодавы взяты из [@sapphi-red/web-noise-suppressor](https://github.com/sapphi-red/web-noise-suppressor).
